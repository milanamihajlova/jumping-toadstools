# Прыгающие поганки 4.0 — Тёмная магическая академия

Визуальное обновление версии 3.0. **Многопользовательская логика Socket.IO не изменена**: комнаты, тактики, энергия, заклинания, препятствия, таймер и таблица победителей сохранены.

## Новое
- Готическая оранжерея с арочными окнами и декоративной трассой.
- Пять нарисованных SVG-поганок, анимация прыжков и дыхания.
- Световые эффекты заклинаний и событий; всплывающие объявления.
- Необязательные звуковые сигналы, выключены по умолчанию.
- Адаптация для телефона и поддержка `prefers-reduced-motion`.

## Установка через GitHub и Render
1. Сохраните резервную копию текущих `index.html` и `server.js`.
2. В существующем репозитории замените **только `index.html`** на файл из этого архива. Он должен быть рядом с `server.js` и `package.json` в корне репозитория.
3. Выполните Commit changes. Render автоматически опубликует обновление.
4. Проверьте создание комнаты и гонку в двух браузерах.

`server.js` и `package.json` в архиве — совместимые копии из версии 3.0; менять их не требуется.

## Локальный запуск
`npm install` затем `npm start`, открыть `http://localhost:3000`.

Комнаты и результаты хранятся в памяти сервера, после рестарта сбрасываются. Автоматического восстановления сессии нет.
