# 🍄 Прыгающие поганки — многопользовательская игра

Браузерная игра для сообщества ВКонтакте: общие комнаты, синхронные раунды, видимая всем трасса и таблица победителей.

## Локальный запуск

1. Установите Node.js 18 или новее.
2. В папке проекта выполните `npm install`.
3. Выполните `npm start`.
4. Откройте `http://localhost:3000`.
5. Для теста откройте ещё одну вкладку, введите другое имя и присоединитесь по коду комнаты.

## Публикация

Разместите проект на Node.js-хостинге с поддержкой постоянных WebSocket-соединений (например, Render или Railway). Команда сборки: `npm install`; команда запуска: `npm start`. Для Render подойдёт тип Web Service. Поделитесь полученной HTTPS-ссылкой в беседе ВКонтакте. Это обычный веб-сайт, не зарегистрированный VK Mini App.

## Правила

- 2–24 игрока в комнате.
- 30 клеток до финиша; 16 секунд на раунд.
- Осторожно: `max(3, d6)`.
- Обычно: `d6`.
- Рискнуть: при d6 4–6 результат `d6+3`, при d6 1–3 результат `1`.
- Если игрок не выбрал тактику, применяется обычный прыжок.
- Игра завершается, когда все финишировали или после 20 раундов.
- Победители определяются по пройденной дистанции; при одинаковой дистанции порядок разрешается сервером.

## Ограничения первой версии

- Комнаты хранятся в оперативной памяти сервера и исчезают после его перезапуска.
- При закрытии вкладки игрок выходит из комнаты; при переподключении нужно войти снова.
- Нет учётных записей VK, антибот-защиты и долговременного рейтинга.
- Для публичного турнира рекомендуется добавить постоянные идентификаторы, БД, переподключение и административную авторизацию.
