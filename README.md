# 🍄 Прыгающие поганки 3.0 — Магический хаос

Многопользовательская браузерная игра для сообщества ВКонтакте. Node.js + Express + Socket.IO.

## Установка на GitHub и Render

Замените в **корне** существующего репозитория `server.js` и `index.html` файлами из этого архива. `package.json` можно оставить прежним (в архиве он также есть). Не загружайте ZIP вместо файлов.

Render: Root Directory — пустое поле, Build Command — `npm install`, Start Command — `npm start`. После Commit дождитесь Deploy succeeded / Live. Веб-адрес остаётся прежним.

## Локальный запуск

Node.js 18+; `npm install`, затем `npm start`. Откройте http://localhost:3000.

## Правила

- Ведущий создаёт комнату, другие игроки входят по коду. От 2 до 24 участников.
- 30 клеток до финиша, максимум 18 раундов, каждый раунд 20 секунд.
- Все начинают с 5 энергии (максимум 5).
- Осторожный прыжок: 1–3 клетки, бесплатно.
- Большой прыжок: 2 энергии, бросок 1–6; при 3–6 — 4–7 клеток, при 1–2 — 0.
- Магическая выходка: 1 энергия, 1–2 клетки и случайное заклинание (Протего, Локомотор, Импедимента, Конфундус).
- Передышка: +1 клетка, +2 энергии.
- С вероятностью 30% на ход выпадает событие: удобрение, силки, росток или ветер.
- Все действия вычисляются сервером. Можно указать цель заклинания. Протего блокирует одну вредную атаку или силки. Импедимента замедляет следующий прыжок.
- Победа: первым достичь 30 клеток; после лимита раундов — по дистанции. При одновременном финише выше тот, у кого больше продвижение за последний ход.

## Ограничения

Комнаты хранятся только в памяти сервера: после перезапуска Render они исчезнут. При разрыве соединения игроку нужно войти снова (во время гонки присоединение закрыто). Не предназначено для платных соревнований или долгосрочного хранения результатов.

## Проверка

Откройте игру в двух браузерах, создайте комнату и присоединитесь по коду, затем проведите несколько раундов и перезапустите гонку.
